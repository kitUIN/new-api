# 分组限时倍率

在「分组定价」选中具体分组，添加限时倍率规则并保存。每条规则包含启用开关、倍率、周期、起止时间和备注；每周规则还需选择星期。倍率允许为 0。

- 一次性：指定北京时间的日期和时间，例如 `2026-10-13T09:00` 至 `2026-10-13T12:00`。
- 每小时：例如 `00:15` 至 `00:45` 表示每小时第 15 至 45 分钟；结束可以为 `01:00`。
- 每天：例如 `09:00` 至 `18:00`；结束允许 `24:00`。
- 每周：指定星期及时间；星期为时段开始所在日，0 为周日，1 至 6 为周一至周六。

全部使用北京时间 UTC+8，包含开始、不包含结束。循环规则结束早于开始时跨至下一周期，如每周一 `23:00–02:00` 持续到周二凌晨。一次性结束必须晚于开始。重叠时使用列表中首条启用且命中的规则，可通过「提高优先级」调整顺序。

命中规则时覆盖普通倍率和用户专属倍率；规则结束后自动恢复。组合分组按实际路由选中的成员分组计算，例如选中 A 时使用 A 当前的限时倍率。重试切换成员时重新计算。规则自动分组的筛选、排序以及价格接口使用当前有效倍率。

计费阶段记录命中规则快照，使用日志以橙色显示限时倍率；悬浮可查看划掉的原实际倍率、限时倍率、该次生效时段、持续分钟数和备注。异步任务持久化提交时的倍率，完成结算和退款日志继续使用快照，配置修改或活动结束不会改写历史日志。

配置通过现有选项接口存储在 `group_ratio_setting.group_timed_ratios`，无需增加数据表：

```json
{
  "A": [
    {
      "enabled": true,
      "ratio": 0.5,
      "kind": "weekly",
      "start": "09:00",
      "end": "18:00",
      "weekdays": [1, 3, 5],
      "remark": "周一、三、五日间优惠"
    }
  ]
}
```

计费倍率统一从 `ResolveGroupRatioAt` 获取；`GetGroupRatio` 与 `GetGroupRatioCopy` 保留基础配置语义，用于配置编辑、上游倍率同步及历史记录。日志扩展字段为 `timed_group_ratio`，包含 `original_ratio`、`ratio`、`start`、`end` 和 `remark`，起止时间使用 Unix 秒。
