# GreatMaoHive 服务探针

管理员登录 new-api 后，可从顶栏进入 **服务探针**（`/service-probes`）。普通用户和未登录访客无法访问页面及其数据接口，IP 地址仅随管理员接口返回。

## 连接蜂巢

在 **系统设置 → 运维设置 → 服务探针** 中填写蜂巢地址和只读 API 密钥，并打开启用开关后保存。沿用系统设置的超级管理员权限。配置保存在数据库中，保存成功后当前实例立即生效，无需重启；其他实例按现有系统配置同步周期更新。

密钥不会回传给前端，已配置时输入框仅显示提示。留空保存会保留原密钥；输入新密钥则替换。关闭开关可暂停探针读取，保留连接配置。

尚未在页面保存过配置时，也兼容服务端环境变量（修改环境变量后需重启）：

```dotenv
GREATMAO_HIVE_URL=https://hive.example.com:7443
GREATMAO_HIVE_READ_API_KEY=蜂巢的Hive.ReadApiKey
```

地址为蜂巢根地址，可包含部署路径前缀，不要附加 `/api/v1`。使用受信任的 HTTPS 证书；本地 HTTP 调试需在蜂巢显式启用 `Hive:AllowInsecureTransport`。密钥不添加 `Bearer` 前缀，不使用小蜜蜂 Token，也不要配置为前端环境变量。未配置时页面显示连接说明；请求失败时显示错误和刷新入口。

蜂巢需支持以下只读接口：

- `/api/v1/bees/traffic/quotas`：包含所有已配置小蜜蜂，包括尚未连接的节点。
- `/api/v1/bees/{id}/online/history`：online、offline、unknown 区间。
- `/api/v1/bees/{id}/traffic/current`：实时上下行，单位 bit/s。

名称、地区和 IP 在小蜜蜂的 `Bee:Name`、`Bee:Region`、`Bee:Ip` 配置。常见地区名称和地区代码匹配本地旗帜图标；无法匹配时使用地球图标，原始地区名称仍完整展示。IPv4 默认仅显示第一段（如 `154.*.*.*`），其他地址默认显示 `****`；点击可显示完整 IP，再次点击隐藏。额度和周期在蜂巢的 `Hive:Bees[].Quota` 配置。

## 展示口径

卡片采用紧凑的分层布局：顶部展示地区旗帜、名称和连接状态，中间突出实时上下行速率，再展示周期流量及剩余额度圆环，底部展示在线历史和时间范围。流量区域左侧固定分为两行：总用量与额度、下行与上行用量；未设上限时同样保持两行。圆环展示剩余百分比，余量不超过 20% 时为黄色，耗尽时为红色；未设上限时显示「∞」。重置时间在用量的悬停或聚焦提示中展示，不单独占行。节点编号、最后联系时间、采样时间和告警说明也可聚焦或悬停查看。

- 周期用量为上下行合计，采用二进制单位（GiB、TiB）。`null` 表示没有采样，`0` 表示真实零用量；未设上限与零额度分别显示。
- 重置时间直接采用蜂巢的 `periodEnd`，按浏览器本地时区显示。有采集缺口时显示提示，实际流量可能更高。
- 实时速率将接口的 bit/s 除以 8，采用十进制字节单位 B/s、KB/s、MB/s 等显示，每 10 秒刷新；离线、无采样和超时显示 `—`。额度每 30 秒刷新，历史每 60 秒刷新，页面不在前台时暂停定时刷新。
- 在线历史可切换最近 1 小时、24 小时、7 天，每个窗口分成 48 格。包含离线区间的格子显示红色，否则包含未知区间时显示灰色；聚焦或悬停查看具体时段及三种状态时长。在线比例以整个窗口为分母。
- 未知表示蜂巢未观测到该时段，不等同离线。在线仅表示小蜜蜂与蜂巢的有效连接，不代表所有业务服务可用。历史查询末端保留 5 秒时钟余量。

后端使用固定的三个只读资源，不接受任意目标 URL，不跟随重定向；密钥保留在后端，接口响应禁止缓存。
